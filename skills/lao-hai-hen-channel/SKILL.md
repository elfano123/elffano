# ช่อง/เพจ "เล่าให้เห็น"

เรื่องเล่าผีและสยองขวัญ เล่าเป็นการ์ตูนอนิเมชั่นสไตล์ผี มีโทนภาพเฉพาะ ใช้ engine อนิเมชั่นที่มีในเครื่องผู้ใช้ (ตั้งค่าไว้หมดแล้ว) พากย์ผ่าน ElevenLabs (เชื่อมแล้ว) ลงทั้ง YouTube (Long + Shorts), TikTok และเพจ ภาษาไทย

**จุดขาย:** ชื่อ "เล่าให้เห็น" = ไม่ใช่แค่เล่า แต่ทำให้เห็นภาพ และ **เรื่องของคนดูคือวัตถุดิบหลัก** เรื่องจึงมีให้เล่าไม่หมด

## สถานะ: ร่างแรก (13 พ.ย. 2026) ยังรอผู้ใช้บอก
- engine ที่ใช้ + พาธ + วิธีรัน (ผู้ใช้บอกว่า "เดี๋ยวบอกอีกที")
- โทนภาพ/พาเลตต์/ตัวละครผู้เล่า (ถ้ามี) สไตล์ผีที่ต้องการ
- เสียง ElevenLabs: ใช้เสียงไหน ตั้งค่าอย่างไร ผู้ชาย/หญิง ตัวละครในเรื่องใช้เสียงต่างกันไหม
- ความยาว Long ที่ต้องการ และความถี่การลง
เมื่อได้ข้อมูลแล้วให้เติมหัวข้อ "Pipeline" และ "สไตล์ภาพ" ด้านล่าง ระหว่างนี้อย่าเดาค่าพวกนี้เอง

## แหล่งเรื่อง
**ระยะแรก (ยังไม่มีฐานคนดู — ผู้ใช้สั่ง 13 พ.ย. 2026): ใช้เรื่องที่คนโพสต์ไว้ที่อื่นเป็นหลัก** เน้นเรื่องจาก **ไทย ลาว และเอเชีย** (สุ่มสลับประเทศ ไม่ให้ชุดเรื่องซ้ำประเทศติดกันเกิน 2 คลิป) เมื่อมีคนดูแล้วค่อยย้ายน้ำหนักไปเรื่องจากผู้ชม ตอนนี้ยังใส่ CTA ชวนส่งเรื่องทุกคลิปเพื่อสะสมเรื่องรอไว้

1. **เรื่องจากที่อื่น (หลักในระยะแรก):** พันทิป, Reddit (r/nosleep, r/thailand, r/LaoPeople ฯลฯ), 4chan, เว็บ/ฟอรัม/บล็อกภาษาไทย ลาว เวียดนาม ญี่ปุ่น เกาหลี จีน อินโดนีเซีย ฟิลิปปินส์ ฯลฯ ที่คนโพสต์ประสบการณ์ลี้ลับ
   - เรื่องภาษาอื่นให้แปล + เรียบเรียงใหม่เป็นภาษาพูดไทย ใส่ความรู้ท้องถิ่นสั้นๆ ที่คนไทยอาจไม่รู้ (ธรรมเนียม ความเชื่อของประเทศนั้น) เฉพาะที่จำเป็นต่อการเข้าใจเรื่อง
2. **เรื่องจากผู้ชม (เพิ่มทีหลังเมื่อมีฐานคนดู):** รับผ่านฟอร์ม/DM/คอมเมนต์ ต้องมีข้อความยินยอมให้ "นำไปเล่า ดัดแปลง และใช้เชิงพาณิชย์" ให้เครดิตผู้ส่งตามที่ผู้ส่งต้องการ (ชื่อ/นามแฝง/ไม่ระบุ)
**วิธีเรียบเรียงเรื่องจากที่อื่น (ใช้กับข้อ 1):**
   - **เรียบเรียงใหม่เป็นภาษาพูดไทย ไม่แปลทื่อๆ ทั้งโพสต์ และไม่ลอกประโยค** ปรับโครงให้เหมาะกับจังหวะอนิเมชั่น
   - ให้เครดิตที่มาในคำอธิบาย (แพลตฟอร์ม + ชื่อผู้โพสต์ถ้ามี + ลิงก์) ถ้าเจ้าของเรื่องระบุเงื่อนไขการใช้ไว้ ให้ทำตาม
   - ถ้าเจ้าของเรื่องติดต่อมาขอให้ถอด ให้ถอดและแจ้งผู้ใช้ทันที
3. **ไม่ใช้ตำนาน/นิทานพื้นบ้านเป็นเรื่องหลัก (ผู้ใช้สั่ง 13 พ.ย. 2026: "ไม่เอาตำนาน เน้นประสบการณ์หลอน")** เน้น **ประสบการณ์หลอนที่คนเล่าจากชีวิตจริงของตัวเอง** (บุคคลที่หนึ่ง/เล่าสิ่งที่เจอเอง) ความเชื่อท้องถิ่นใช้ได้แค่เป็นบริบทประกอบในเรื่อง ไม่ใช่ตัวเรื่อง

คลังแหล่งเรื่อง รายชื่อ และวิธีหาเรื่องยาว ดูไฟล์ `sources.md` ในโฟลเดอร์เดียวกัน

## เรื่องยาว = แบ่งเป็น Ep (ผู้ใช้สั่ง 13 พ.ย. 2026)
- **เรื่องที่ยาวเกิน ~10 นาที ให้แบ่งเป็น Ep** ตัดที่จุดที่คนอยากดูต่อ (ปมใหม่ปรากฏหรือเรื่องหักเลี้ยว) ไม่ตัดกลางฉากไร้เหตุผล
- **CTA ใส่เฉพาะตอนจบของแต่ละ Ep** ไม่ใส่กลางเรื่อง ทุก Ep จบด้วยปมค้าง + ทีเซอร์สั้นๆ ของ Ep ถัดไป แล้วค่อย CTA "ส่งเรื่องหลอนมาให้เรา เดี๋ยวเล่าให้เห็น"
- **ออกแบบให้ต่อเป็นตอนรวม (รวม Ep) ได้ภายหลัง:**
  1. ส่วนที่ซ้ำทุก Ep (อินโทร, สรุปตอนก่อน 1 ประโยคต้น Ep 2+, ทีเซอร์ท้าย Ep, CTA) ทำเป็นก้อนแยก ตัดออกได้โดยไม่กระทบเรื่อง
  2. ชื่อไฟล์เรียงตามลำดับ (`<ชื่อเรื่อง>_EP01`, `_EP02`…) ใช้ชื่อฉากต่อเนื่องกัน
  3. เสียงดนตรี/ฉากหลังต่อเนื่องกันได้ ไม่ตัดจบกะทันหันที่ท้าย Ep เว้นแต่ตั้งใจให้เป็นปมค้าง
- ชื่อคลิป: "<ชื่อเรื่อง> | EP.1" และใส่ลิงก์ Ep ก่อนหน้า/ถัดไปใน description + เพลย์ลิสต์
- ตอนรวม EP ทำหลังจบทุก Ep: ตัดก้อนซ้ำออก ใส่อินโทร/ CTA ครั้งเดียว แบ่งชื่อบทใน description เป็นไทม์สแตมป์ตาม Ep
- ตอนเสนอไอเดีย บอกว่าเรื่องไหนแนะนำให้ทำเป็นกี่ Ep

## กฎเรื่องเล่า (ห้ามข้าม)
1. **ไม่อ้างว่าเป็น "เรื่องจริง" ถ้าพิสูจน์ไม่ได้** ใช้ "ผู้ส่งเล่าว่า", "มีคนเล่าว่า", "จากประสบการณ์ที่ผู้ส่งเล่ามา"
2. **ตัดข้อมูลระบุตัวบุคคลออก** ชื่อ นามสกุล ที่อยู่ เบอร์ ที่ทำงาน โรงเรียน สถานที่เจาะจงที่คนจะไปตามรังควานได้ ใช้ชื่อสมมติ/คำอธิบายกว้างๆ
3. **ไม่เอาเหตุจริงมาเล่นเป็นผีเอาสนุก** คดีฆาตกรรม อุบัติเหตุ ภัยพิบัติ หรือคนที่เสียชีวิตจริงและระบุตัวได้ ไม่ใช้เป็นตัวผี/ฉากหลอน ถ้าเรื่องผู้ชมอิงเหตุจริง ให้ถามผู้ใช้ก่อน
4. **ไม่ล้อเลียนความเชื่อ ศาสนา เชื้อชาติ หรือกลุ่มคน** ผีและความเชื่อเล่าด้วยความเคารพ ไม่ใส่คำเหยียด
5. **ไม่มีภาพ/คำบรรยายความรุนแรงเกินไป** (เลือดสาด ศพ การทำร้ายตัวเอง/ฆ่าตัวตายแบบเห็นวิธี) ความน่ากลัวมาจากบรรยากาศ เสียง สิ่งที่ "ไม่เห็น" ไม่ใช่ภาพโหด ถ้าเรื่องมีหัวข้อฆ่าตัวตาย/ทำร้ายตัวเอง ให้ถามผู้ใช้ก่อนและไม่ลงรายละเอียดวิธี
6. **เรื่องเด็กและคนที่เปราะบาง** ถ้าตัวละครหลักเป็นเด็กและเรื่องมีความรุนแรง ให้ถามผู้ใช้ก่อน
7. **ไม่ปลุกความกลัวเกินจริงเรื่องสถานที่/กลุ่มคนจริง** ไม่ชี้ว่าสถานที่จริงถูกสาป ถ้าไม่มีที่มา
8. **ผู้ใช้สั่งทำ = ลงมือทำจนจบ** (เหมือนช่องอื่น) ผู้ใช้ถาม/ขอความเห็น = ตอบในแชทก่อน ไม่แก้ไฟล์เอง
9. **ผู้ใช้เป็นคนพากย์หรือสั่งใช้เสียง** ตามที่ผู้ใช้เลือก ไม่ตั้งเอง

## โครงคลิป
**Long (ประมาณ 5–10 นาที ปรับตามเรื่อง):**
1. **ฮุก ~3–10 วินาที** หยุดคนดูให้ได้ (ดูสูตรฮุกด้านล่าง) ห้ามหลอกคลิก
2. อินโทรสั้นของช่อง (ถ้ามี ไม่เกิน ~5 วินาที ไม่ขัดจังหวะ)
3. ปูพื้น: ใคร ที่ไหน ตอนไหน ทำไมถึงอยู่ตรงนั้น (ให้ปกติที่สุดก่อน)
4. **ไต่ระดับ 3–4 ชั้น:** สิ่งผิดปกติเล็กๆ → ผิดปกติชัดขึ้น → ตัวละครพยายามอธิบาย/หนี → จุดที่รู้ว่าไม่ใช่เรื่องธรรมดา
5. **จุดพีค/สะดุ้ง** (1 จุดใหญ่) + ภาพ/เสียงรองรับ แล้วปล่อยให้เงียบสั้นๆ
6. **ปิดแบบค้างคา:** สิ่งที่ยังอธิบายไม่ได้ หรือรายละเอียดเล็กๆ ที่ทำให้ขนลุกตอนย้อนคิด
7. **CTA:** "ถ้าคุณเคยเจอประสบการณ์หลอนๆ ส่งเรื่องมาให้เรา เดี๋ยวเล่าให้เห็น" + บอกช่องทางส่ง (ลิงก์ฟอร์ม/DM) + ชวนกดติดตาม

**Shorts/TikTok (~45–90 วินาที):** ฮุก 1–3 วินาที → 3–4 บล็อกไต่ระดับ → สะดุ้ง/ค้างคา → CTA ประโยคเดียว ไม่มีอินโทรยาว

## สูตรฮุก (เลือกให้ตรงเรื่อง ไม่หลอกคลิก)
- **เริ่มกลางเหตุการณ์:** "ตีสองครึ่ง ประตูห้องน้ำที่ล็อกอยู่ เปิดออกเอง"
- **ความขัดแย้งที่ไม่น่าเป็นไปได้:** "ห้องนี้ไม่มีใครอยู่ แต่กล้องจับได้ว่ามีคนเดินอยู่ข้างใน"
- **กติกาแปลกๆ:** "ป้าเจ้าของหอบอกว่า ห้ามเปิดไฟทางเดินหลังเที่ยงคืน"
- **ผลลัพธ์ที่ค้างคา (ไม่เฉลยตอนจบ):** "ผมไม่เคยเล่าเรื่องนี้ให้ใครฟัง จนถึงวันนี้"
- ห้ามขึ้นต้นด้วย "วันนี้จะมาเล่า…", "เรื่องนี้เป็นเรื่องจริง…", คำทักทายยาว ชื่อช่อง
- ภาพเฟรมแรกต้องมีภาพที่แรงที่สุดแล้ว (ไม่ fade จากดำยาว) ข้อความฮุก 2–5 คำบนจอ ตรงกับเสียง

## จังหวะระทึก (ในการเขียนบทพากย์)
- ประโยคสั้นตอนตึงเครียด ยาวตอนปูบรรยากาศ ใช้ "ความเงียบ" (เว้นจังหวะ) ก่อนเผยสิ่งผิดปกติ
- เล่ารายละเอียดประสาทสัมผัส: เสียง กลิ่น อุณหภูมิ ไฟ เงา (สิ่งที่คนดูจินตนาการต่อได้) มากกว่าบอกว่า "น่ากลัว"
- ให้ตัวละครสงสัยและหาเหตุผลก่อนเสมอ ผีควรมาหลังคนดูพยายามอธิบายด้วยเหตุผลแล้ว
- ภาษาพูดเข้าปาก ไม่ทางการ ไม่เป็นสำนวนเขียน (ใช้หลักเดียวกับช่องลืมไม่ลง) วลีติดปากแต่ละอันไม่เกิน 1 ครั้งต่อคลิป

## ระบบรับเรื่องจากผู้ชม
**ฟอร์มรับเรื่อง** (Google Form หรือกรอกใน DM) ช่อง: เรื่องที่เจอ (เล่าได้ยาวตามสะดวก) · เกิดขึ้นเมื่อไหร่/ที่ไหนโดยกว้างๆ · ใช้ชื่อสมมติไหม/ให้ใส่เครดิตแบบไหน · ช่องติดต่อกลับ (ไม่บังคับ) · ช่องติ๊กยินยอม: "ข้าพเจ้ายินยอมให้ช่อง 'เล่าให้เห็น' นำเรื่องนี้ไปเล่า ดัดแปลง ตัดต่อ และเผยแพร่ในทุกช่องทาง รวมถึงใช้เชิงพาณิชย์ และยืนยันว่าเป็นเรื่องที่ข้าพเจ้าเรียบเรียงเองหรือมีสิทธิ์ส่ง"
**ขั้นตอนเลือกเรื่อง:** อ่านคัด → ตัดข้อมูลระบุตัวตน → ตรวจกฎเรื่องเล่า → เรียบเรียงเป็นบล็อกฉาก → ส่งผู้ใช้พิจารณา
**ตอนเล่า:** ขอบคุณผู้ส่งตามเครดิตที่เลือกในคลิป (ท้ายคลิปหรือ description)
